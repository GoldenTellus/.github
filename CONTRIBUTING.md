# GoldenTellus Contributing Guide

Thank you for your interest! GoldenTellus focuses on **open-sourcing production-tested AI capabilities** extracted from real enterprise deployments.

## 🎯 What We Accept

### Capabilities (Primary)
All capability contributions go to **[goldentellus-capabilities](https://github.com/GoldenTellus/goldentellus-capabilities)**.

See that repo's [CONTRIBUTING.md](https://github.com/GoldenTellus/goldentellus-capabilities/blob/main/CONTRIBUTING.md) for:
- Quality standards (production-tested, universal format, self-contained)
- Submission process (proposal → review → merge)
- Maintenance expectations

### Documentation
Improvements to [goldentellus-home](https://github.com/GoldenTellus/goldentellus-home):

- **Typo fixes**: Open a PR directly
- **Content suggestions**: Open an issue first
- **New pages**: Discuss via issue before writing

## 🚫 What We Don't Accept

- Training materials or tutorials (not our focus)
- Proprietary code or customer data
- Capabilities without production validation
- Generic integrations already covered by existing tools

## 📝 Commit Convention

Use [Conventional Commits](https://www.conventionalcommits.org/):

- `feat(skills): add retail-inventory-forecast`
- `fix(tools): correct auth header in crm-connector`
- `docs: clarify SNAO deployment requirements`
- `chore: update manifest format version`

## 🔒 Security

Report vulnerabilities via private disclosure (GitHub Security Advisory) rather than public issues.
